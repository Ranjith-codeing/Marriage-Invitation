# Background music (optional)

Place your song here as:

```
public/audio/wedding-music.mp3
```

- When the file exists, guests see **"Open the invitation ♫"** (with music) and **"Enter without music"**,
  plus a ♫ Music / Pause button. Music never autoplays with sound.
- When it's missing, all music controls are hidden automatically.
- Keep it under ~5 MB (128–160 kbps MP3 is plenty). Make sure you have the right to use the track publicly.
- Change the file name or volume in `src/config/assets.js` → `audio`.
